** Garbage Collection
Set garbage collection 32mb. Disable GC during startup and minibuffer
sessions.

#+name: garbage-collection
#+begin_src emacs-lisp
  ;;;;;;;;;;;;;;;;
  ;; garbage-collection
  ;;;;;;;;;;;;;;;;
  ;; Disable GC during init, and re-enable upon startup.
  (setq gc-cons-threshold most-positive-fixnum)
  (add-hook 'emacs-startup-hook (lambda ()
                                  (setq gc-cons-threshold 33554432)))

  ;; Create hook and associated functions to disable GC during active
  ;; minibuffer sessions.
  (add-hook 'minibuffer-setup-hook (defun mgk/garbage-collect@minibuffer-enter ()
                                     (setq gc-cons-threshold most-positive-fixnum)))
  (add-hook 'minibuffer-exit-hook (defun mgk/garbage-collect@minibuffer-exit ()
                                    (setq gc-cons-threshold 33554432)))

  ;; Create a hook and function that performs garbage collection on
  ;; Focus Change.  It should make emacs feel a little snappier I
  ;; guess.
  (add-function :after after-focus-change-function
    (defun mgk/garbage-collect@frame-focus-change ()
      (unless (frame-focus-state)
        (garbage-collect))))
#+end_src

*** Run Downs
- [[help:gc-cons-threshold][gc-cons-threshold]] :: This is the important GC declaration. It
  determines when and how often GC occurs. Low values make GC happen
  more often, while higher values make it happen less often.  It
  requires a balance. I based my decision for the value of this
  variable upon the recommendations of hlissner in [[https://github.com/doomemacs/doomemacs/issues/3108#issuecomment-627537230][this github issue]].

- most-positive-fixnum :: This sets gc-cons-threshold to max value,
  essentially disabling garbage collection.

- [[help:minibuffer-setup-hook][minibuffer-setup-hook]] :: We use the setup hook for the minibuffer to
  disable GC while it is open.  This helps ensure a smooth minibuffer
  experience.

- [[help:minibuffer-exit-hook][minibuffer-exit-hook]] :: The exit hook for the minibuffer is ran when
  the minibuffer closed or done with.  Here, we turn GC back on.

** Hide Frame Until Loaded
By default when Emacs is ran, it will load and pop up instantly, and
then will begin loading plugins and themes etc.

This can cause things like, having to witness a horrible white screen
in a dimly lit work area and other visible horrors.

To prevent myself from having to witness such digital contortions, I
use the following hook to prevent Emacs from displaying anything at
all until it is fully loaded.

It causes further delays to Emacs startup, but I find it preferable to
watching all that flickering going on.

#+name: hide-frame-until-loaded
#+begin_src emacs-lisp
  ;;;;;;;;;;;;;;;;
  ;;hide-frame-until-loaded
  ;;;;;;;;;;;;;;;;
  ;; Hide emacs until it is fully loaded.
  (add-to-list 'initial-frame-alist '(visibility . nil))
  (add-hook 'after-init-hook (lambda () (make-frame-visible)))
#+end_src

** Bootstrap Straight.el
This is a package manager for Emacs that makes configuring packages a
little easier. They advertise it as a purely functional
next-generation package manager for Emacs.

This first part bootstraps straight.el and gets it ready for use by setup.el.

- [[https://github.com/radian-software/straight.el][Straight.el on Github]].

#+name: bootstrap-straight.el
#+begin_src emacs-lisp
  ;;;;;;;;;;;;;;;;
  ;; bootstrap-straight.el
  ;;;;;;;;;;;;;;;;
  (setq package-enable-at-startup nil)
  (defvar bootstrap-version)
  (let ((bootstrap-file
         (expand-file-name "straight/repos/straight.el/bootstrap.el" user-emacs-directory))
        (bootstrap-version 6))
    (unless (file-exists-p bootstrap-file)
      (with-current-buffer
          (url-retrieve-synchronously
           "https://raw.githubusercontent.com/radian-software/straight.el/develop/install.el"
           'silent 'inhibit-cookies)
        (goto-char (point-max))
        (eval-print-last-sexp)))
    (load bootstrap-file nil 'nomessage))
  ;; Disable neutering mode.  It slows down minibuffer completion.
  (straight-package-neutering-mode -1)
#+end_src

** No-Littering
To help ensure emacs extensions don't 'litter' config files around the
users Emacs directory, someone developed this handy tool
'no-littering'.

While not perfect, it does do a really good job. Typically it tries to
encourage extensions to use a ./etc dir found inside the primary emacs
config directory.

- [[https://github.com/emacscollective/no-littering][No-Littering on Github]].

#+name: no-littering
#+begin_src emacs-lisp

  ;; no-littering
  ;;;;;;;;;;;;;;;;

        (expand-file-name ".etc/config/" user-emacs-directory))
  (setq no-littering-var-directory
        (expand-file-name ".etc/data/" user-emacs-directory))
  (straight-use-package 'no-littering)

** Backup Settings and Autosaves
I have a few requirements for backups:

- Long filenames with lots of built in meta information right in the
  filename itself. Emulating an ssh://user@host:dir/file.txt URI.
- More backups than average.  Back ups every save.  Not just when a
  file is first opened as is default.

#+name: backup-settings
#+begin_src emacs-lisp
  ;; Configure and setup backup and autosave directories first.

  (setq
   mgk/autosave-folder "~/.cache/backups/autosaves/"
   mgk/backups-folder "~/.cache/backups/edits/")
  (unless (file-exists-p mgk/autosave-folder)
    (make-directory mgk/autosave-folder t))
  (unless (file-exists-p mgk/backups-folder)
    (make-directory mgk/backups-folder t))

  ;; Backups
  (setq
   backup-by-copying t  ;; Don't clobber symlinks
   backup-directory-alist
   `(("." . ,mgk/backups-folder))) ;; Where to put regular backups. (foobar.txt~)

  ;; Autosaves.
  (setq
   auto-save-file-name-transforms `((".*" ,mgk/autosave-folder t));; Location of autosaves.
   auto-save-list-file-prefix mgk/autosave-folder ;; Set prefix for autosaves. 
   tramp-auto-save-directory mgk/autosave-folder) ;; Autosave tramp files locally.

  ;; Rename Backups
  ;; This my custom backup file naming function.  Intended to emulate
  ;; ssh uri's.
  (defun mgk/make-backup-file-name (file)
    "Subroutine of `make-backup-file-name--default-function'.
  The function `find-backup-file-name' also uses this."
    (let ((alist backup-directory-alist)
          elt backup-directory abs-backup-directory)
      (while alist
        (setq elt (pop alist))
        (if (string-match (car elt) file)
            (setq backup-directory (cdr elt)
                  alist nil)))
      ;; If backup-directory is relative, it should be relative to the
      ;; file's directory.  By expanding explicitly here, we avoid
      ;; depending on default-directory.
      (if backup-directory
          (setq abs-backup-directory
                (expand-file-name backup-directory
                                  (file-name-directory file))))
      (if (and abs-backup-directory (not (file-exists-p abs-backup-directory)))
          (condition-case nil
              (make-directory abs-backup-directory 'parents)
            (file-error (setq backup-directory nil
                              abs-backup-directory nil))))
      (if (null backup-directory)
          file
        (if (file-name-absolute-p backup-directory)
            (progn
              (when (memq system-type '(windows-nt ms-dos cygwin))
                ;; Normalize DOSish file names: downcase the drive
                ;; letter, if any, and replace the leading "x:" with
                ;; "/drive_x".
                (or (file-name-absolute-p file)
                    (setq file (expand-file-name file))) ; make defaults explicit
                (cond
                 ((file-remote-p file)
                  ;; Remove the leading slash, if any, to prevent
                  ;; convert-standard-filename from converting that to a
                  ;; backslash.
                  (and (memq (aref file 0) '(?/ ?\\))
                       (setq file (substring file 1)))
                  ;; Replace any invalid file-name characters, then
                  ;; prepend the leading slash back.
                  (setq file (concat "/" (convert-standard-filename file))))
                 (t
                  ;; Replace any invalid file-name characters.
                  (setq file (expand-file-name (convert-standard-filename file)))
                  (if (eq (aref file 1) ?:)
                      (setq file (concat "/"
                                         "drive_"
                                         (char-to-string (downcase (aref file 0)))
                                         (if (eq (aref file 2) ?/)
                                             ""
                                           "/")
                                         (substring file 2)))))))
              ;; This is where I needed to start tweaking the
              ;; 'make-backup-file-name-1' function so I could prepend to it.
              ;; Appending was easy and could be done without modification.
              (let ((mgk/filename (subst-char-in-string ?/ ?% file))
                    (mgk/timestamp (format-time-string "%F.%T.%z")))
                (concat
                 (expand-file-name mgk/backups-folder)
                 mgk/filename "##"
                 user-login-name "@" system-name ","
                 mgk/timestamp "~")))))))

  ;; This is where we tell Emacs what backup-file-name-function we actually want to use.
  (setq make-backup-file-name-function #'mgk/make-backup-file-name)

  ;; Force backups on every save like a true insane person.
  (defun mgk/force-backup-of-buffer ()
    (setq buffer-backed-up nil))
  (add-hook 'before-save-hook  'mgk/force-backup-of-buffer)
#+end_src

use the mouse to select the window I want to work in, then take over

    (defun hot-expand (str &optional mod header)
      "Expand org template.

  STR is a structure template string recognised by org like <s. MOD is a
  string with additional parameters to add the begin line of the
  structure element. HEADER string includes more parameters that are
  prepended to the element after the #+HEADER: tag."
      (let (text)

        (when mod (insert mod) (forward-line))

  (defun mgk/set-background-for-terminal (&optional frame)
   (or frame (setq frame (selected-frame)))
   "unsets the background color in terminal mode"
   (unless (display-graphic-p frame)
     (set-face-background 'default "unspecified-bg" frame)))

- (defun mgk/set-background-for-terminal (&optional frame)
   (or frame (setq frame ([[help:selected-frame][selected-frame]])))
   "unsets the background color in terminal mode"
   ([[help:unless][unless]] ([[help:display-graphic-p][display-graphic-p]] frame)
     ([[help:set-face-background][set-face-background]] 'default "unspecified-bg" frame)))

  - First we are creating a custom function which we will tie into
    hooks. Whenever the hooks are triggered, this custom function will
    call '(set-face-background 'default "unspecified-bg" frame)' to
    remove the background color. Unless the selected frame is a
    graphic frame (non-terminal). In which case it leaves the
    background alone.

  - Lastly we tie the custom function into after-make-frame-functions
    and window-setup-hook to have our custom function run when ever

#+name: lisp/+setup.el
#+begin_src emacs-lisp :tangle ./lisp/+setup.el :mkdirp yes
  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; Additional keywords for setup.el
  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; These are extra keywords added to setup.el.  They are all copied
  ;; from the website.
  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; Autoloading
  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; This can be useful when working with local Lisp files.
  (setup-define :autoload
    (lambda (func)
      (let ((fn (if (memq (car-safe func) '(quote function))
                    (cadr func)
                  func)))
        `(unless (fboundp (quote ,fn))
           (autoload (function ,fn) ,(symbol-name (setup-get 'feature)) nil t))))
    :documentation "Autoload COMMAND if not already bound."
    :repeatable t
    :signature '(FUNC ...))

  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; Unconditional quit
  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; By default, :only-if, :if-host, etc. can be used to abort the
  ;; evaluation of a setup body. In some cases one might want to
  ;; unconditionally abort, e.g. when using a complex conditional
  ;; construct. In that case, :quit generates the right code:
  (setup-define :quit
    #'setup-quit
    :documentation "Unconditionally abort the evaluation of the current body.")

  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; Bound unconditional quitting
  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; Bound unconditional quiting In case one doesn’t want the entire
  ;; setup body from being aborted because of :only-if, :if-host,
  ;; :quit, etc. you can use this following to limit its scope:
  (setup-define :with-local-quit
    (lambda (&rest body)
      `(catch ',(setup-get 'quit)
         ,@body))
    :documentation "Prevent any reason to abort from leaving beyond BODY."
    :debug '(setup))

  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; Deferred loading
  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; If you want to load the current feature after a series of other
  ;; features, this macro can help automatically define the code to do
  ;; so:
  (setup-define :load-after
    (lambda (&rest features)
      (let ((body `(require ',(setup-get 'feature))))
        (dolist (feature (nreverse features))
          (setq body `(with-eval-after-load ',feature ,body)))
        body))
    :documentation "Load the current feature after FEATURES.")

  ;; Note that multiple arguments can be passed to :after-load,
  ;; leading to multiple encapsulated with-eval-after-load blocks.

  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; Remove the current mode from the mode line.
  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; The ModeLine uses `minor-mode-alist` to map active minor modes
  ;; to indicators. This macro makes manipulating the variable easier:
  (setup-define :hide-mode
      (lambda (&optional mode)
        (let* ((mode (or mode (setup-get 'mode)))
               (mode (if (string-match-p "-mode\\'" (symbol-name mode))
                         mode
                       (intern (format "%s-mode" mode)))))
          `(setq minor-mode-alist
                 (delq (assq ',mode minor-mode-alist)
                       minor-mode-alist))))
    :documentation "Hide the mode-line lighter of the current mode.
  Alternatively, MODE can be specified manually, and override the
  current mode."
    :after-loaded t)

  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; Removing hooks
  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; It is sometimes desirable to modify hooks buffer-locally, such as
  ;; in the case of ‘flymake-diagnostic-functions’.
  ;; Example:
  ;; (setup flymake
  ;;   (:hook-into prog-mode text-mode org-src-mode)
  ;;   (:with-mode org-src-mode
  ;;     (:local-unhook flymake-diagnostic-functions #'elisp-flymake-checkdoc)))
  (setup-define :unhook
    (lambda (func)
      `(remove-hook (quote ,(setup-get 'hook)) ,func))

    :repeatable t
    :ensure '(func)
    :signature '(FUNC ...))

    (lambda (hook &rest functions)
      `(add-hook
        (quote ,(setup-get 'hook))
        (lambda ()
          ,@(mapcar
             (lambda (arg)
               (let ((fn (cond ((eq (car-safe arg) 'function) arg)
                               ((eq (car-safe arg) 'quote)    `(function ,(cadr arg)))
                               ((symbolp arg)                 `(function ,arg))
                               (t                             arg))))
                 `(remove-hook (quote ,hook) ,fn t)))
             functions))))
    :documentation "Remove FUNCTION from HOOK only in the current hook."
    :debug '(&rest sexp)
    :repeatable nil)

  (setup-define :advise
      (lambda (symbol where arglist &rest body)
        (let ((name (gensym "setup-advice-")))
    `(progn
       (defun ,name ,arglist ,@body)
       (advice-add ',symbol ,where #',name))))
    :documentation "Add a piece of advice on a function.
  See `advice-add' for more details."
    :after-loaded t
    :debug '(sexp sexp function-form)
    :indent 3)

  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; If you wish to only configure a system when a executable is
  ;; installed, the following macro will ensure that the evaluation is
  ;; interrupted, when this is not the case:
  (setup-define :needs
      (lambda (executable)

           ,(setup-quit)))
    :documentation "If EXECUTABLE is not in the path, stop here."
    :repeatable 1)

  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; Hostname checking
  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; You sometimes want to configure a system only on one host. The
  ;; following macro can be used to easily check your hostname, and
  ;; prevent evaluation of a setup body, if you are on the “wrong”
  ;; host:
  (setup-define :if-host
      (lambda (hostname)
        `(unless (string= (system-name) ,hostname)
           ,(setup-quit)))
    :documentation "If HOSTNAME is not the current hostname, stop evaluating form.")

  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; Manual load-path manipulation
  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; If you want to add a directory to your load-path the following
  ;; macro can do so. Additionally, it will abort the evaluation if
  ;; the directory doesn’t exist and can be used as the head element.
  (setup-define :load-from
      (lambda (path)
        `(let ((path* (expand-file-name ,path)))
           (if (file-exists-p path*)
               (add-to-list 'load-path path*)
             ,(setup-quit))))
    :documentation "Add PATH to load path.
  This macro can be used as NAME, and it will replace itself with
  the nondirectory part of PATH.
  If PATH does not exist, abort the evaluation."
    :shorthand (lambda (args)
                 (intern
                  (file-name-nondirectory
                   (directory-file-name (cadr args))))))

  ;; Install PACKAGE with MIN-VERSION or higher
  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  (setup-define :package-min-version
      (lambda (package min-version)
        `(let ((min-version (quote ,min-version)))
           (when (stringp min-version)
             (setq min-version (version-to-list min-version)))
           (unless (package-installed-p ',package min-version)
             (cl-labels
                 ((find-best (pkg)
                             (car (sort (cdr (assoc pkg package-archive-contents))
                                        (lambda (a b)
                                          (version-list-<= (package-desc-version b)
                                                           (package-desc-version a))))))
                  (good-enough (pkg)
                               (and pkg
                                    (version-list-<= min-version (package-desc-version pkg)))))
               (let
                   ((best-pkg (find-best ',package)))
                 (if (good-enough best-pkg)
                     (package-install best-pkg)
                   (package-refresh-contents)
                   (let ((best-pkg (find-best ',package)))
                     (if (good-enough best-pkg)
                         (package-install best-pkg)
                       (error "No version of %s >= %S is available" ',package min-version))))))
             (package-installed-p ',package min-version))))
      :documentation "Install PACKAGE with MIN-VERSION or higher if it hasn't been installed yet.
        This macro can be used as NAME, and it will replace itself with
        the first PACKAGE."
      :repeatable t
      :shorthand #'cadr)

  ;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;;
  ;; Add the main ":straight" keyword
  ;;;;;;;;;;;;;;;;
  (setup-define :straight
    (lambda (recipe)
      `(unless (straight-use-package ',recipe)
         ,(setup-quit)))
    :documentation
    "Install RECIPE with `straight-use-package'.
            This macro can be used as HEAD, and will replace itself with the
            first RECIPE's package."

                 (let ((recipe (cadr sexp)))
                   (if (consp recipe)
                       (car recipe)
                     recipe))))

  ;;;;;;;;;;;;;;;;
  ;; Add the conditional ":straight-when"
  ;;;;;;;;;;;;;;;;
  (setup-define :straight-when
    (lambda (recipe condition)
      `(if ,condition
           (straight-use-package ',recipe)
         ,(setup-quit)))
    :documentation
    "Install RECIPE with `straight-use-package' when CONDITION is met.
          If CONDITION is false, stop evaluating the body.  This macro can
          be used as HEAD, and will replace itself with the RECIPE's
          package.  This macro is not repeatable."
    :repeatable nil
    :indent 1
    :shorthand (lambda (sexp)
                 (let ((recipe (cadr sexp)))
                   (if (consp recipe) (car recipe) recipe))))

  ;;;;;;;;;;;;;;;;
  ;; Prefix-less ":option" alternative
  ;;;;;;;;;;;;;;;;
  ;; Example:
  ;; (setup foo (:option* bar "baz"))
  ;; expands to:
  ;; (customize-set-variable 'foo-bar "baz" "Set for foo's setup block")
  (setup-define :option*
    (lambda (name val)
      `(customize-set-variable
        ',(intern (format "%s-%s" (setup-get 'feature) name))
        ,val
        ,(format "Set for %s's setup block" (setup-get 'feature))))
    :documentation "Set the option NAME to VAL.
  NAME is not the name of the option itself, but of the option with
  the feature prefix."
    :debug '(sexp form)
    :repeatable t)

  ;;;;;;;;;;;;;;;;
  ;; File extension association
  ;;;;;;;;;;;;;;;;
  (setup-define :file-match
    (lambda (glob)
      `(add-to-list 'auto-mode-alist (cons ,(wildcard-to-regexp pat) ',(setup-get 'mode))))
    :documentation "Associate the current mode with files that match GLOB."
    :debug '(form)
    :repeatable t)

  ;;;;;;;;;;;;;;;;
  ;; Customizing faces
  ;;;;;;;;;;;;;;;;
  ;; Example:
  ;; (setup (:straight forge)
  ;;     (:load-after magit)
  ;;     ;; Make it easier to see that a topic was closed.
  ;;     (:face forge-topic-closed ((t (:strike-through t)))))
  (setup-define :face
      (lambda (face spec) `(custom-set-faces (quote (,face ,spec))))
      :documentation "Customize FACE to SPEC."
      :signature '(face spec ...)
      :debug '(setup)
      :repeatable t
      :after-loaded t)

  ;;;;;;;;;;;;;;;;
  ;; Add documentation to setup block
  ;;;;;;;;;;;;;;;;
  ;; Similar to leaf.el :doc keyword. The doc alist could be, for
  ;; example, fed to marginalia, and provide annotations to minibuffer
  ;; completions.
  (defvar setup--doc-alist nil "AList of docs for setup blocks.")

  (setup-define :doc
    (lambda (string)
      `(add-to-list 'setup--doc-alist '(,(setup-get 'feature) . ,string)))
    :documentation "Allow documentation using STRING.
  This will be ignored at expansion."
    :signature '(STRING ...)
    :repeatable nil)

  (provide '+setup)
#+end_src

** Hooking Into Graphical or Tty Mode
I got this howto from this page here.

If I need to run a function or hook into graphical mode vs tty mode, these examples are how:

#+begin_src emacs-lisp
  ;; Run on graphical instances:
  (add-hook 'after-make-frame-functions
            (lambda ()
              ;; we want some font only in GUI Emacs
              (when (display-graphics-p)
                (set-frame-font "DejaVu Sans Mono 28"))))


  ;; Run on terminal instances.
  (add-hook 'after-make-frame-functions
            (lambda ()
              ;; we do something only in terminal Emacs
              (unless (display-graphics-p)
                (xterm-mouse-mode 1))))
#+end_src

** Example Setup.el Hooks
This comes up for me all the time.  I fight with the hooks all the
time still, so like to compare with references frequently.

*Basic Example:*
#+begin_src emacs-lisp
  (setup foo-mode
    (:hook bar-mode))
#+end_src

/Expands Into:/
#+begin_src emacs-lisp
  (add-hook 'foo-mode-hook #'bar-mode)
#+end_src


*Applying Context:*
#+begin_src emacs-lisp
  (setup foo-mode
    (:with-mode baz-mode
      (:hook qux-mode))
    (:hook bar-mode))
#+end_src

/Expands Into:/
#+begin_src emacs-lisp
  (progn
    (add-hook 'baz-mode-hook #'qux-mode)
    (add-hook 'foo-mode-hook #'bar-mode))
#+end_src

Or More Generally:
#+begin_src emacs-lisp
  (setup 
    (:with-feature foo-mode
      (:hook bar-mode)))
#+end_src

*Example Hook Into:*
#+begin_src emacs-lisp
  (setup flymake
    (:bind "M-n" #'flymake-goto-next-error
           "M-p" #'flymake-goto-prev-error)
    (:hook-into prog-mode))
#+end_src

*Unhook Example for Specific Mode:*
#+begin_src emacs-lisp
  (setup flymake
    (:hook-into prog-mode text-mode org-src-mode)
    (:with-mode org-src-mode
      (:local-unhook flymake-diagnostic-functions #'elisp-flymake-checkdoc)))
#+end_src
